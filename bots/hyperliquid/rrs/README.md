# RRS Trading Strategy

- Compute return of Stock i minus return of SPY over a look‑back window.
- Divide that differential by the stock’s realized volatility (e.g. daily std) and maybe by its average volume.
- A steadily rising RRS (with smooth, low‑vol price action and creeping volume) = institutional footing.
- A spike in price + RSI without volume/volatility confirmation = likely retail-fueled “fake” breakout
