# 🚀 Moon Dev Trading Bots

Welcome to Moon Dev's Trading Bot Collection! This repository contains various trading strategies, backtesting tools, and implementation code for cryptocurrency and stock trading.

## 📚 The RBI Method

Our development process follows the RBI method:

### 🔍 Research
- Find promising trading strategies
- Study market patterns and indicators
- Analyze historical performance

### 📊 Backtest
- Test strategies against historical data
- Optimize parameters
- Validate performance metrics

### 💻 Implement
- Deploy successful strategies as live bots
- Start with minimal position sizes
- Monitor and adjust as needed

> ⚠️ **Important**: Past performance doesn't guarantee future results. Always start with small positions!

## 🏃‍♂️ Quick Start Guide

The repository is organized into three main folders:

### 📁 /backtests
- Contains all backtesting code
- Example: `rsi_guppy.py` - RSI + Guppy strategy backtest
- Uses `backtesting.py` framework for testing

### 📁 /bots
- Live trading bot implementations
- Production-ready trading strategies
- Connection to various exchanges

### 📁 /data
- Historical price data
- Data downloading scripts
- Data processing utilities

## 🛠️ Setup & Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/moon-dev-trading-bots.git
```

2. Install dependencies
```bash
pip install -r requirements.txt
```

3. Run a backtest
```bash
python backtests/rsi_guppy.py
```
