# 🚀 Moon Dev Trading Bots

Welcome to Moon Dev's Trading Bot Collection! This repository contains various trading strategies, backtesting tools, and implementation code for cryptocurrency and stock trading.

## 📚 The RBI Framework

The foundation of successful algorithmic trading lies in our systematic RBI approach:

### 🔍 Research
- **Academic Sources**
  - Google Scholar papers
  - PhD dissertations
  - Financial journals
- **Trading Knowledge**
  - Market analysis books
  - Expert trader insights
  - Risk management principles
- **Strategy Development**
  - Document trading ideas
  - Define clear rules
  - Set risk parameters

### 📊 Backtest
- **Data Validation**
  - Test multiple timeframes
  - Use clean OHLCV data
  - Verify data sources
- **Strategy Testing**
  - Implement in backtesting.py
  - Include transaction costs
  - Account for slippage
- **Optimization**
  - Fine-tune parameters
  - Test market conditions
  - Analyze performance

### 💻 Implement
- **Bot Development**
  - Start with minimal positions ($10)
  - Implement risk controls
  - Handle order management
- **Deployment**
  - Monitor performance
  - Regular health checks
  - Scale gradually

> ⚠️ **Important**: Past performance doesn't guarantee future results. Always start with small positions and scale gradually!

## 🏃‍♂️ Quick Start Guide

The repository is organized into three main folders:

### 📁 /backtests
- Contains all backtesting code
- Example strategies:
  - `rsi_guppy.py` - RSI + Guppy strategy
  - `directional_index.py` - DMI strategy
- Uses `backtesting.py` framework

### 📁 /bots
- Live trading bot implementations
- Production-ready strategies
- Connection to various exchanges
- Detailed RBI documentation

### 📁 /data
- Historical price data
- Data downloading scripts
- Data processing utilities
- data from yahoo, coinbase & hyperliquid

## 🛠️ Setup & Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/moon-dev-trading-bots.git
```

2. Install dependencies
```bash
pip install -r requirements.txt
```

3. Run a backtest
```bash
python backtests/rsi_guppy.py
```
